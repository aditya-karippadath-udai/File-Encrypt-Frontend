# File Encryption Tool (Aegis)

A local-first, high-security desktop file encryption and decryption utility built with **React**, **TypeScript**, **Tauri 2.x**, and **Rust**.

Designed for complete data sovereignty, cryptographic integrity, and memory safety without external dependencies, cloud synchronization, or telemetry.

---

## Key Features

- **Authenticated Streaming Encryption**: Utilizes **XChaCha20-Poly1305** AEAD with a 192-bit nonce to encrypt files of arbitrary size with constant memory footprint (~64 KiB chunks).
- **Strong Key Derivation**: Employs **Argon2id** (RFC 9106) with configurable memory and time hardness parameters and 128-bit CSPRNG salts (`rand::thread_rng`).
- **Cryptographic Chunk Binding**: Every chunk is individually authenticated with Additional Authenticated Data (AAD) containing the 64-bit chunk index and last-chunk flag, strictly preventing chunk reordering, duplication, injection, or truncation attacks.
- **Zeroization & Memory Hygiene**: All key material, derived keys, and plaintext secrets implement automatic memory scrubbing on drop (`Zeroize`, `ZeroizeOnDrop`).
- **Native Desktop & Browser Fallback**: Runs natively inside Tauri 2.x desktop shell (Windows, macOS, Linux) with native file dialogues, path validation, and hardware-accelerated crypto. Includes an interactive WebCrypto simulation fallback for zero-install previewing.
- **Batch Processing & Queue**: Multi-file drag-and-drop queue with duplicate detection, concurrency controls, pause/resume, individual cancellation, and progress telemetry.
- **Conflict Resolution & Crash Recovery**: Atomic temporary file generation (`.aegis_tmp_*`), conflict resolution policies (`Rename`, `Overwrite`, `Skip`), and automated recovery scanning for orphaned partial operations.
- **Production Hardened**: Zero telemetry, zero unencrypted temporary disk leaks, strict Content Security Policy (CSP), and sanitized error boundaries.

## Getting Started

### Prerequisites

- **Node.js**: 18.0 or higher (`npm` / `bun`)
- **Rust**: 1.77.0 or higher with `cargo` (for desktop release)
- **Platform Dependencies**:
  - **Linux**: `libwebkit2gtk-4.1-dev`, `build-essential`, `curl`, `wget`, `file`, `libssl-dev`, `libgtk-3-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev`
  - **macOS**: Xcode Command Line Tools
  - **Windows**: Visual Studio C++ Build Tools with English language pack

### Development

```bash
# 1. Install frontend dependencies
npm install

# 2. Run frontend in development mode
npm run dev

# 3. Run Tauri desktop application
npm run tauri dev
```

### Production Build

```bash
# Compile frontend production bundle
npm run build

# Build native desktop installers (Debian, AppImage, NSIS, DMG)
npm run tauri build
```

## File Format Specification (v1)

Encrypted containers generated by Aegis follow a binary streaming structure:

```
+-------------------+-----------------+--------------------------------------+
| Magic (5 bytes)   | Version (1 byte)| Crypto Identifiers (3 bytes)         |
| "AEGIS"           | 0x01            | Cipher: 0x01, KDF: 0x01, Nonce: 0x01 |
+-------------------+-----------------+--------------------------------------+
| Argon2 Memory     | Argon2 Time     | Argon2 Threads  | Salt Length (1 byte)|
| 4 bytes (BE)      | 4 bytes (BE)    | 4 bytes (BE)    | Salt Bytes (16 B)   |
+-------------------+-----------------+-----------------+--------------------+
| Base Nonce (24 B) | Chunk Size (4 B)| Encrypted Metadata Length (4 B)      |
+-------------------+-----------------+--------------------------------------+
| Encrypted Metadata Payload (Encrypted JSON: file name, original size, date)|
+----------------------------------------------------------------------------+
| Chunk 1: [Length: 4 B][Last Flag: 1 B][Ciphertext + Poly1305 Tag: 16 B]     |
| Chunk 2: [Length: 4 B][Last Flag: 1 B][Ciphertext + Poly1305 Tag: 16 B]     |
| ...                                                                        |
+----------------------------------------------------------------------------+
```
